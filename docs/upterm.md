## upterm

Instant Terminal Sharing

### Synopsis

Upterm shares a terminal session: you host a command, and guests join it
from their own terminals, through a relay, with upterm join or plain ssh.

Flags can also be set with UPTERM_ environment variables and the config
file: see 'upterm config --help'.

### Examples

```
  # Host $SHELL; upterm prints how guests join it:
  upterm host

  # A guest joins with the connect string the host shares:
  upterm join ssh://ID@uptermd.upterm.dev

  # Or with plain ssh:
  ssh ID@uptermd.upterm.dev
```

### Options

```
      --debug   Enable debug logging (log file: /home/user/.local/state/upterm/upterm.log). A non-empty DEBUG turns it on too.
  -h, --help    help for upterm
```
