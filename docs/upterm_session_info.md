## upterm session info

Show a session, given its name or session ID

### Synopsis

Show a session, given its name or session ID: its status, how guests join
it, who is connected, and what guests may do.

NAME|ID is the session's name (the one 'upterm host' printed, or --name
gave it) or its session ID; 'upterm session list' shows both. A name is
looked up before an ID.

A session that has ended still answers, from the record it left behind: how
it ended.

Output formats:
  -o json   JSON

Exits 4 when no session has the name, and 1 for any other failure.

```
upterm session info NAME|ID [flags]
```

### Examples

```
  # Show the session named build:
  upterm session info build

  # The same session, by its session ID:
  upterm session info d3k5fia7m4us73ehblug

  # As JSON:
  upterm session info build -o json
```
